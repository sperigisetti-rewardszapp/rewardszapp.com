# RewardsZapp Website

A premium responsive landing website for RewardsZapp, a rewards, loyalty, gifting and incentive platform.

## Files

- `index.html` - Main website
- `css/style.css` - Complete styling and responsive design
- `js/script.js` - Mobile navigation and smooth scrolling
- `README.md` - Setup instructions

## Run locally

Simply open `index.html` in a browser.

## Deploy

Upload the complete folder to GitHub, Netlify, Vercel, or your hosting provider.

For `rewardszapp.com`, point your domain DNS to your selected hosting provider.

## Before going live

1. Replace `hello@rewardszapp.com` with your actual business email.
2. Add your final RewardsZapp logo.
3. Replace placeholder statistics with verified company numbers.
4. Add your Privacy Policy and Terms pages.
5. Connect the contact form/CRM if required.
