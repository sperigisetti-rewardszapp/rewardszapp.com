# RewardsZapp Modern Website

A responsive, animated single-page website for RewardsZapp.

## Files
- index.html — complete website structure
- styles.css — responsive visual design and animations
- script.js — menu, scroll effects, reveal animations and counters

## Upload to GoDaddy
1. Download and unzip this package.
2. Upload `index.html`, `styles.css`, and `script.js` into your hosting site's public root folder (commonly `public_html`).
3. Make sure `index.html` is in the root.
4. Visit https://www.rewardszapp.com

## Customize
- Replace `hello@rewardszapp.com` and the demo phone number in `index.html`.
- Replace the sample partner initials and statistics with verified company data.
- Replace reward examples with your actual available brands.
- Google Fonts are loaded from the web; the site otherwise uses only local HTML/CSS/JS.

No backend is required for the landing page.
